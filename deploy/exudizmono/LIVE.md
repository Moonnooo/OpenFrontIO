# Live deployment

The user approved promotion of the full development version on 2 October 2026. The last approved live release is Exudizmono v0.2.4, based on OpenFront main at e02eeba66b4801ebae0b686e1b0e4bc03fbf3654.

For the prepared v0.2.5 release, build with `Dockerfile.release` and tag `frontrank-game:exudizmono-0.2.5`. Both live game and API use this image. Production retains its own database, signing key, account sessions, provider settings and hostname; preview data is never copied into production. v0.2.5 enables server-authoritative naval mode for public FFA, team, special, 1v1 and 2v2 lobbies when both ENABLE_AUTHORITATIVE_NAVAL and ENABLE_PUBLIC_AUTHORITATIVE_NAVAL are true. Existing private naval games and automatic solo naval play remain supported. Public naval mode fails closed if either rollout flag is unavailable. This new public rollout requires separate user approval before updating live. Multiplayer rank badges read the live Exudizmono skill ladders.

Before promotion, back up the live SQLite database using SQLite backup, copy deployment files and static pages into a restricted rollback directory, and retain the previous Docker images. Replace the four mounted API modules and jwt.ts with their repository versions, and replace the mounted app shell with the release image's compiled index.html. Copy the repository stats, clans and credits assets into the public directory. Stamp GIT_COMMIT with the release revision while preserving all other runtime settings.

Recreate both services from `/opt/frontrank/compose.yaml`; verify the public version, metadata, auth provider availability, statistics, clans, solo naval controls and both public and private naval lobbies. Rebuild the downloadable source archive from the deployed revision. To roll back, stop the new services, restore the prior composition, mounted modules, static pages and runtime settings, then restart the retained previous images. Restore the database backup only if required by a failed migration, to avoid discarding results recorded after deployment.
